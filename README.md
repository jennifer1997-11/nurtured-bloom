## ✨ 核心功能

### 🏠 首頁（儀表板與視角切換）
- **個人化孕期導航**：動態顯示目前孕週、累計天數、距離預產期倒數與孕期階段（第一／二／三孕期）。
- **本週寶寶概況**：即時呈現本週寶寶生長插圖、身長估計與貼切生活化的蔬果尺寸比喻。
- **本週身心提醒**：提供媽咪身體變化、產檢要點與生活注意事項。
- **雙重視角設計**：支援「🤰 孕媽咪視角」與「💕 神隊友視角」切換，讓伴侶同步掌握媽咪每週身心變化與貼心陪伴任務。

### 🤰 我的孕期
- **孕期總覽**：依據預產期與目前週數，整合呈現整體孕期旅程、身心指南與神隊友每週任務。
- **產檢地圖**：視覺化 8～40 週共 14 次公費產檢里程碑，清楚標示常規檢查、公費補助超音波、重要自費產檢項目（如 NIPT、羊膜穿刺、高層次超音波等），並支援產檢紀錄與超音波照片預覽。
- **問診備忘錄**：將孕媽咪日常想向醫師諮詢的疑慮與症狀隨手記下，產檢時不再手忙腳亂。
- **孕期日記**：記錄每日心情心情標籤（快樂、安心、疲憊、焦慮等）與孕期珍貴筆記。

### 👶 寶寶成長
- **逐週發育圖鑑**：收錄 1 至 40 週完整胎兒成長資訊與 Q 版浮動視覺動效。
- **發育重點解析**：結構化呈現「01 身體成長」與「02 感官與動作」生理發育脈絡。
- **六大成長里程碑**：縱向時間軸標示心跳初現、器官形成、感受胎動、聽覺開啟、肺部成熟等重大成長節點。

### 🤖 AI 孕期助理
- **專業衛教問答**：針對孕期日常飲食、運動指引、身體變化及常見不適進行即時問答。
- **受控知識庫索引**：以結構化 Medical Knowledge Base 作為孕期衛教資訊的重要知識來源，提升回答內容的可追溯性與一致性。
- **醫療安全邊界**：具備安全防護設計，明確標示為衛教參考資訊，不提供疾病診斷、處方建議，遇危急徵兆即刻引導就醫。

### 💬 媽咪交流社群
- **公開交流牆**：提供友善溫馨的互動空間，依孕期生活、經驗交流與日常心情進行發文。
- **互動交流**：支援按讚、留言互動，並自動顯示發文者的暱稱與當前孕週標記。

## 💗 個人化體驗

平台提供輕量直覺的個人化設定：
- **媽咪與寶寶專屬設定**：自訂媽咪暱稱、預產期（EDD）、懷孕胎數、寶寶小名與性別。
- **自動推算引擎**：依據設定之預產期精準計算當前懷孕週數、累計天數及剩餘天數。
- **本地狀態儲存**：MVP 階段採用瀏覽器 `localStorage` 保存使用者資料與日記紀錄，開箱即用、免繁瑣註冊流程。

> ⚠️ *註：目前 MVP v1.0 採用瀏覽器客戶端儲存機制，尚未包含多裝置雲端同步或帳號密碼登入系統。*

## 📚 Medical Knowledge Base（受控醫療知識庫）

「孕育之美」以結構化 Medical Knowledge Base 管理孕期衛教資料，並逐步應用於網站衛教內容與 AI 孕期助理：

- **單一信任來源**：Production 環境僅允許載入與渲染 `review_status = "approved"` 的醫療紀錄檔案。
- **權威資料來源**：
  - **衛生福利部國民健康署**：《孕媽咪衛教手冊》、《孕媽咪健康手冊》、《爸爸孕產育兒衛教手冊》、孕產兒關懷網站
  - **衛生福利部（MOHW）** 官方衛生政策與孕產婦公費補助規範
  - **英國國家醫療服務體系（NHS）** 官方逐週胎兒發育指引（Week-by-week pregnancy guide）

### ⚠️ 醫療免責聲明
> 本平台所提供之所有孕期發育、產檢指南、飲食運動與衛教問答內容，均以健康促進與衛教資訊整理為目的，**絕不能取代專業醫師之面診、醫療診斷、處方或個別化治療建議**。若孕期出現任何異常出血、劇烈腹痛、嚴重水腫、胎動明顯減少或其他急性不適，請立即前往醫療院所就診。

## 🛠️ 技術架構

- **前端核心（Frontend）**：
  - HTML5 語意化結構（Semantic Markup）
  - Vanilla CSS3（自建 Design System Tokens、HSL 柔和粉調調色盤、Glassmorphism、微動效）
  - Vanilla JavaScript（ES6+ 單頁式應用程式 SPA 架構，零外部龐重框架依賴，極速載入）
- **客戶端儲存（Client-side Storage）**：
  - Web Storage API（`localStorage` 保存個人化 Profile、日記與任務勾選狀態）
- **資料與後端整合（MVP Backend & Data）**：
  - Google Apps Script（`Code.gs` 提供 MVP 後端 API 與 Google Sheets 資料串接）
  - Google Sheets（作為社群發文與互動資料之持久化試算表資料庫）
- **受控資料庫（Controlled Knowledge Base）**：
  - 結構化 JSON Medical Records（嚴格 Schema 定義與審核追蹤）
- **版本控制與部署（Version Control & Deployment）**：
  - Git & GitHub
  - GitHub Pages（純靜態網頁自動化託管）

## 🚀 本機執行

本專案為純前端靜態架構，無須複雜建置環境：

1. **複製專案庫**：
   ```bash
   git clone https://github.com/jennifer1997-11/pregnancy-beauty.git
   ```
2. **開啟專案**：
   - 使用 VS Code 開啟專案資料夾。
   - 使用 VS Code **Live Server** 擴充套件啟動本機伺服器，或直接於瀏覽器中開啟 `index.html`。
